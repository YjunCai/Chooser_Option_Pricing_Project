# 工具演示视频脚本 — Chooser Option Pricing Tool（5–10 分钟）

> 配套交付物：`streamlit_app.py`（可部署定价工具）。
> 录制方法：用 OBS / Xbox Game Bar / 系统录屏录制屏幕 + 麦克风解说，横屏 1920×1080 更佳。
> 每节给出建议时长与旁白。总时长约 7–8 分钟（可控在 5–10 分钟范围内）。

---

## 0. 准备（录制前）

```bash
cd E:/实习交付/week2/week8
streamlit run streamlit_app.py        # 启动工具（http://localhost:8511）
```

浏览器打开 http://localhost:8511，等待页面加载完成。

## 1. 开场与项目背景（约 0:00–0:50）

**画面**：标题区（BSM 与 ML 双轨定价指标卡）。

**旁白**：

> 现在看到的是工具的定价主界面，它实现 BSM 与最优机器学习模型的双轨定价。"

---

## 2. 双轨定价与误差范围（约 0:50–2:10）

**画面**：页面顶部四张指标卡；光标移到侧边栏"定价模式"。

**操作**：
1. 在侧边栏"ML 模型"下拉框中依次切换 `XGBoost (实盘首选)` → `VIX-proxy (隐含波动率)` → `GBDT-anchored (波动率比率)`。
2. 观察顶部"ML 定价"与"BSM(vol_21d) 价格"的变化及价差 delta。

**旁白**：
> "顶部四张卡显示双轨定价结果：左边是 BSM(vol_21d) 静态波动率的定价，右边是机器学习模型定价，中间是二者的价差。
> 我切换不同的 ML 模型，可以看到预测波动率不同导致定价不同。
> 页面底部还给出了当前定价的误差条——也就是各模型在 2024 年测试集上的定价 MAE，帮助交易员量化模型不确定性。"

---

## 3. 价格趋势（约 2:10–3:20）

**画面**：点击标签页"📈 价格趋势"，滚动到两张趋势图。

**旁白**：
> "第二个重要功能是价格趋势。工具在 2018 到 2024 年的完整历史区间上，用 BSM 和最优 ML 模型重新定价了选择权，并把趋势延伸到最新实时市场状态。
> 可以看到蓝色是 BSM 基线，红色是 XGBoost、橙色是 VIX-proxy。
> 下面这张图是波动率输入随时间的变化——ML 预测的波动率通常高于已实现波动率，这正是市场为波动率支付的溢价（IV premium），也是机器学习提升定价精度的关键。"

---

## 4. 敏感性分析（约 3:20–4:20）

**画面**：点击"📊 敏感性分析"标签页；依次拖动侧边栏参数。

**操作**：
1. 修改侧边栏"行权价 K"或"选择日 t1"滑块。
2. 观察四个敏感性图表（价格 vs S / σ / t1 / r）实时刷新。

**旁白**：
> "这是交互式敏感性分析。我调整合约参数，四个图表实时刷新，展示选择权价格随标的现价、波动率、选择日和利率的变化。
> 可以看到 ML 线与 BSM 线的形态差异，这反映了两种波动率输入对价格敏感性的不同传导。"

---

## 5. 极端场景测试（约 4:20–5:20）

**画面**：点击"🌪 极端场景"标签页。

**旁白**：
> "极端场景面板内置了波动率激增 50%、利率上调 2%、组合冲击和 VIX 冲击四类压力场景。
> 表格同时给出 BSM、XGBoost 和 VIX-proxy 三套模型的价格及相对基准变动。
> 在 ATM 基座下，波动率 +50% 使 BSM 上涨约 49%、ML 模型上涨约 70–80%；而 VIX 冲击下静态 BSM 无反应，ML 模型通过特征重工程捕捉到了市场恐慌。这正说明了 ML 增强模型在极端市场下的价值。"

---

## 6. 性能指标仪表板（约 5:20–6:10）

**画面**：点击"🏆 性能指标"标签页。

**旁白**：
